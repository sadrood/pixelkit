# PixelKit 在线工具箱

一个自己搭的在线工具站：**图片、文档、PDF、二维码、计时计数、AI 助手、3D 小游戏、世界电台、影视发现**等 16 个工具，打开即用、无需注册。
图片与文档类工具**全部在浏览器本地完成**，不上传、不留存。

- 在线地址：<http://139.9.176.191:8081/>
- 技术栈：Vite + React 19（前端）· Node.js + Express 5（后端）· nginx + PM2（部署）

## 技术栈与目录

```
src/
  main.js                 SPA 入口：页面注册与 showPage 切换
  pages/                  每个工具一个页面模块（QrPage / AgentPage / …）
  styles/                 样式（main.css 基础 + agent.css 聊天页 + 各页样式）
  agent/                  聊天页用的 Markdown 渲染、情绪系统等
server.js                 后端：文件转换、AI 网关、活码、二维码文件、协同
lib/ai-retry.js           限流重试 / 熔断 / 并发闸门（可离线单测）
docs/                     设计文档、功能说明、验收记录
scripts/                  自检脚本（对比度巡检、截图、限流自测等）
public/                   静态资源（字体、第三方库）
```

**AI 网关路由**：支持接入多家 OpenAI 兼容的模型网关 —— 模型 id 里**带 `/`** 的走备用网关，其余走主网关。
这样切换主对话模型时，不会把识图 / 画图 / 研究等绑定在主网关上的能力一起打挂。
网关地址、密钥与模型 id **全部由部署环境变量注入**，代码里不写死任何一家的账号信息。限流与降级细节见 `docs/AI限流与稳健性.md`。

## 本地开发

```bash
npm install                 # 安装依赖（Node 18+）
cp .env.example .env        # 按需填写，见下表（仓库里没有 .env，属机密）

npm run dev                 # 只跑前端（Vite，默认 5173）
npm run dev:server          # 只跑后端（默认 3001，可用 PORT 覆盖）
npm run dev:all             # 两个一起跑
npm run build               # 构建前端到 dist/（后端会自动托管 dist/）
npm start                   # 只跑后端（生产用法）
```

后端会**自动托管 `dist/`**（存在时），所以生产上只跑 `node server.js`，不暴露源码。

### 环境变量（`.env`）

`.env` **不进仓库**（`.gitignore` 已覆盖 `.env`、`.env.*`、`.env.bak*`）。

| 变量 | 用途 |
| --- | --- |
| `PORT` | 后端端口（生产 3001 / 测试 3002） |
| `OPENAI_BASE_URL` | 主模型网关地址（OpenAI 兼容；取值由部署时配置） |
| `MAIN_KEY_POOL` | 主网关 key 池，逗号分隔（对话 / 画图共用） |
| `DUAL_KEY_POOL` | 内测池 key（“内测双 AI”模式） |
| `OPENAI_MODEL` | 主对话模型 id（带 `/` 表示走备用网关） |
| `OPENAI_FALLBACK_MODEL` | 兜底模型（主模型失败时自动切换） |
| `OPENAI_VISION_MODEL` | 识图模型 id |
| `IMAGE_MODEL` | 画图模型 id（供应商侧模型下线时需更新，见发布记录） |
| `ALT_API_KEY` | 备用模型网关 key（启用备用网关 / 免费模型时需要） |
| `TMDB_API_KEY` | 可选：影视发现的电影数据（TMDB 免费申请）；不配置则只有剧集（TVmaze） |
| `CHAT_REASONING_EFFORT` | `none` / `low` / `medium` / `high`，关掉推理能明显降低首字延迟 |
| `PUBLIC_BASE_URL` | 站点对外地址，用于生成二维码文件链接、活码短链 |
| `CORS_ALLOWED_ORIGINS` | 需要跨域时显式列白名单（默认不发 CORS 头） |
| `AI_MAX_CONCURRENT` / `AI_MIN_GAP_MS` / `AI_BREAKER_*` | 上游限流相关的旋钮 |

## 部署

部署走 **git push + 服务器端钩子**，不手工改服务器文件：

```bash
git push deploy test    # 推到测试环境（/opt/pixelkit-test，端口 3002）
git push deploy main    # 推到生产环境（/opt/pixelkit-prod，端口 3001）
```

`deploy` 远程指向自建裸仓库；服务器上的 `post-receive` 钩子负责：检出分支 →
同步到目标目录（排除 `data/` 与 `.env`）→ `npm install` → `npm run build` → `pm2 restart` → 健康检查。

nginx 放在前面做反代（`/api/`、`/collab`、`/qr/`、`/fs/`、`/s/`），其余走静态与 SPA 兜底。
`deploy.ps1` / `deploy.sh` 里是常用的运维命令封装。

## 安全设计（没有账号体系，靠设备标识）

- **归属隔离**：会话、文件中转站、活码都必须带设备标识（`userId`），服务端严格校验归属；
  列表只返回自己的，读 / 统计 / 删除非本人一律 **403**，没带标识 **401**。
  历史遗留的“无主”数据一律隐藏。
- **错误处理统一**：所有接口出错返回 JSON，**不外泄堆栈**；缺参归为 400。
- **CORS 默认关闭**：不做跨域授权，避免任意站点在访客浏览器里读数据。
- **不泄露实现细节**：关闭 `X-Powered-By`，静态资源只给构建产物。
- **短链跳转公开**：`/s/<code>` 无需登录（扫码的人当然不用登录），但**计数与统计只有创建者能看**。

> 注意：这套方案防的是“别人随手看到你的数据”，**不是**抗住知情的攻击者 ——
> 设备标识存在浏览器本地，没有密码学签名。要真正多用户，需要引入登录体系。

## 二维码工具（功能最全的一块）

- **生成**：尺寸 / 容错 L M Q H / 前景背景色 / **渐变**；
  **输出格式可选 PNG、JPG、WebP、SVG（矢量）**；
  样式可选 **经典方块、圆角方块、圆点（太阳码风格）**，定位点方形或圆形。
  > “太阳码风格”指外观（圆点阵 + 圆形定位点）。**真正的微信小程序码（太阳码）必须调微信官方接口**，
  > 需要小程序 `AppID` + `AppSecret`，本站不代持这类凭据。
- **批量解码**：一次拖入几十张图片，本地逐张解码，结果可复制或导出 CSV（带 BOM，Excel 不乱码）。
- **批量扫码**：调摄像头连续扫，扫到就记一条并继续；相同内容 3 秒内只记一次；
  页面切走或标签页隐藏会自动关闭摄像头。
- **批量生成**：每行一条（或上传 CSV / TXT / **.xlsx**），逐张按当前设置生成，**打包 ZIP 下载**并提供预览。
  `.xlsx` 直接解析（xlsx 即 zip + XML，用 JSZip 读，无额外依赖）。
- **活码（短链 + 扫码统计）**：二维码里放短链，之后换目标不用重新印码；
  提供累计次数、按天分布、最近扫码记录；短链可删。
- **文件活码**：上传文件生成可访问链接（二维码内容为链接），支持原文件下载。

## AI 助手说明

- 前端**流式输出**，支持停止生成、重新生成、会话列表、复制、Markdown 渲染。
- 支持联网搜索、看图、按描述**生成信息图**、文件问答。
- **降级链**：主模型不可用时按候选项自动切换（跨供应商），并在界面上如实显示“实际使用的模型”。
- **限流稳健性**：区分“分钟窗口限流 / 每秒限流 / 配额或权限拒绝”三类，分别退避、熔断或切供应商；
  详见 `docs/AI限流与稳健性.md`。离线单测：`node scripts/ai-retry-check.mjs`。
- 若配置了备用网关，可开启“只允许免费模型”策略：收费模型在接口层就被拒绝、兜底层再拦一道。

## 已知限制

- 没有账号体系（见“安全设计”），多用户场景需要先补登录。
- 站点对外是 **HTTP**，未上 HTTPS（上传与对话内容是明文传输）。
- AI 回答质量取决于所接的模型；免费模型波动较大（延迟与稳定性都会跳）。
- 工具页没有 URL 路由：地址栏不变，浏览器后退会退出站点，也不能分享直达链接。
- `data/` 下的会话、活码、上传记录属于运行时数据，**不入库**，迁移服务器需要单独备份。
