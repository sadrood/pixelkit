# PixelKit「成长模拟器」玩法设计文档

> 状态：设计稿 v2（多剧本架构 + 剧本①：重生之我是公务员）
> 形式：内置到 PixelKit 首页的单页游戏（vanilla JS，不依赖后端与 AI，离线可用）
> 核心理念：**一个引擎 + 多套剧本**。引擎管数值/事件/选择/结算，剧本定义世界观、属性、事件库、结局。

---

## 0. 一句话定位

**成长模拟器** = 文字人生模拟平台：每一局你「重生」成一个剧本设定的人生，在年龄自动推进中做选择、用主动行动经营，一路走到终局结算。后续可以不断加新剧本（退休返聘的教师、白手起家的创业者、海归科研人员…）。

---

## 1. 通用引擎（所有剧本共享）

### 1.1 剧本（Scenario）数据结构
一个剧本 = 一个可独立编写的数据包：

```
Scenario {
  id, title, intro(重生开局文案),
  attributes:[{key,label,min,max,初始规则}],   // 该剧本的属性表
  stages:[{id,label,ageMin,ageMax,stepYears,大事件池Id}],
  events:{ big:[...], small:[...], node:[...] }, // 按阶段分池
  actions:[...],       // 主动行动库（可阶段解锁）
  statuses:[...],      // 状态定义（含互斥/持续修正）
  endings:[...]        // 结局模板与结算文案
}
```

### 1.2 核心循环（不变）
```
开局(重生intro+出身/初始分配) → 按岁段自动推进
每岁段：主动行动(0~2次) → 阶段大事件(必选,2~3选项) → 概率小事件
→ 属性/金钱/状态变化 → 履历记录 → 下一岁段
→ 终局 → 结算(S~D + 评语 + 履历 + 成就)
```

### 1.3 通用规则
- 属性统一 0~100；事件选项可带 `need`（属性≥N/钱≥N/状态）与权重。
- 状态持续修正（每岁段结算一次）+ 事件池过滤。
- 少量负面随机事件（病痛/变故/职场打击），保留真实感与重开欲。
- localStorage 持久化：成就图鉴 + 历史最佳；不做整局存档。

## 2. 剧本①：重生之我是公务员

### 2.1 人设与开局
- **重生设定（轻包装）**：开局短文案「你重生了，回到 2001 年，前世蹉跎半生，这一世你决定……」，随后进入出身选择。
- **出身选择**（影响初始人脉与家庭支持）：
  - 普通工人家庭（初始人脉少、金钱少，抗风险差）
  - 基层干部家庭（初始人脉中、熟悉体制规则）
  - 经商家庭（金钱多，但体制内对"生意家庭"观感微妙）

### 2.2 公务员属性表（0~100）
| 属性 | 含义 | 影响 |
|---|---|---|
| 笔杆子 `pen` | 材料/公文/写作能力 | 写材料成功率、办公室认可、晋升材料考核 |
| 会来事 `so`（情商） | 察言观色、关系经营 | 站队/应酬/领导印象 |
| 酒量体能 `vita` | 应酬酒量+身体 | 酒桌过关、健康 |
| 廉洁定力 `clean` | 底线意识 | 廉政风险事件化解概率 |
| 考运 `exam`（初始高） | 应试能力 | 考公/遴选/在职学历 |
| 人脉资源 `guanxi` | 关系网络 | 借调/晋升提名/办事顺利 |
| 金钱 `money` | 工资+家庭支持 | 生活水平、部分事件 |

> 声望/群众口碑并入 `so` 相关事件处理。

### 2.3 人生阶段（体制时间线）
| 阶段 | 年份 | 步长 | 主题事件 |
|---|---|---|---|
| 求学 | 2001~2005（大学） | 1 年 | 专业选择、公务员备考、学生会、情侣 |
| 上岸 | 2005~2008（入职科员） | 1 年 | 乡镇/县局、办公室、写材料、新人背锅 |
| 基层爬坡 | 2008~2015（副科~正科） | ~1.5年 | 借调、评比、驻村、站队萌芽 |
| 中坚 | 2015~2025（正科~副处/处级） | ~1.5年 | 岗位选择（核心部门/边缘单位）、廉政风险、巡视、应酬 |
| 高位或转身 | 2025~2040 | ~2 年 | 再上一步 or 转岗/躺平/风险爆发 |
| 晚年 | 2040 后 | 每段数年 | 退休待遇、发挥余热、子女、回忆复盘 |

### 2.4 大事件方向与示例（每个阶段 8~12 条池子）
- 求学：`选考公还是考研`、`进学生会刷简历`、`家里劝你早点找对象`
- 上岸：`第一份材料被打回 N 次`、`领导让你背个不大不小的锅`、`被借调到县里写大材料`
- 基层：`单位竞聘，报不报？`、`驻村一年`、`老领导要退了，要不要跟？`
- 中坚：`有笔需要签的字，礼也送到了，签不签？`、`巡视组来了`、`核心部门借调 3 年还是原地提拔`、`应酬喝到胃出血边缘`
- 高位/转身：`组织考察谈话`、`有风声说你要被调整`、`下属出事牵连到你`
- 晚年：`退休返聘`、`写回忆录`、`子女就业要不要"说句话"`

选项带属性门槛示例：
- `签了这笔字`：need money≥?, result 金钱↑、clean↓、risk 腐败标记
- `不签，按规矩来`：need clean≥60，result 安心、可能得罪人（so↓）
- `推给副主任`：need so≥60，result 甩锅成功但树敌

### 2.5 主动行动（解锁节奏同岁段）
写材料(pen↑,可能被加担子) / 跑动经营(so/guanxi↑, 钱↓) / 健身酒局训练(vita↑) / 在职学历(考运+pen) / 业余兼职搞钱(钱↑,clean风险) / 躺平养生(健康↑, 仕途-)/ 参加遴选(换平台)。

### 2.6 状态
`临时工? 上岸在编/乡镇/县局/市直/核心部门/借调/驻村/后备干部/拟提拔/边缘化/被查风险/受处分/抑郁症(极少数)/退休` 等；互斥与阶段过滤。

### 2.7 结局分支（S~D + 评语）
- **S：部级光环退休**（一路顺遂+关键节点全过）
- **A：厅/处级平稳退休**
- **B：科级老黄牛/单位中坚退休**
- **C：躺平安稳/转岗边缘，或提前内退**
- **D：出事**（处分/双开/判刑）、或英年早逝（过劳/重病/酒局意外）
评语由"最高职务+关键事件+是否出事"模板生成，如：`清廉到退休的正处级干部，材料里写尽别人的人生`。

### 2.8 成就（示例，公务员风味）
`上岸成功 / 材料一稿过 / 乡镇三年游 / 核心部门 / 纪律审查全身而退 / 厅级干部 / 群众口碑好 / 老有所依 / 铁窗泪(负面成就)…`

## 3. 里程碑

- **M1**：多剧本引擎（属性/阶段/事件/行动/结算 状态机）+ 单页 UI 骨架 + 剧本①出身与求学阶段打通（含考公上岸）。
- **M2**：剧本① 全阶段事件库（上岸→晚年，大事件 50+、行动 8、状态 15）+ 廉政/负面事件。
- **M3**：结局分支 + 评语 + 履历时间线 + 成就图鉴 + 历史最佳。
- **M4**：文案打磨、移动端适配、平衡数值；预留剧本②加载接口（数据即剧本，写事件库即可扩剧本）。
