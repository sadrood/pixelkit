# 人生之书 · 年龄维度设计稿（v2.4）

> 2026-09-14 起草并**已跑探针校准**。状态：**待落地**（母本尚未改动）。
> 目的：把「年龄」从**显示字段**变成**有后果的维度**，并给「苦结局」补上最有力的一种——**没活到那个岁数**。

---

## 0. 现状实测：年龄只朝一个方向生效

| 事实 | 数据（2026-09-14 实测） |
|---|---|
| 五条线时间轴**完全相同** | `6 → 15 → 17 → 18 → 22 → 28 → 29 → 40 → 45 → 52 → 60 → 78` |
| 事件卡**全部**按年龄放行 | 30/30 张带 `when: s=>s.age>=a&&s.age<=b` |
| 抉择里 `years` 字段 | **0 个**（引擎支持 `if(ch.years)S.age+=ch.years`，从未使用） |
| `endings()` 里出现 `age` | **0 次** |
| **加体魄**的抉择 | **5 个（每线 1 个，全在第 3 章，`+1`）** |
| **减体魄**的抉择 | **20 个** |
| 用体魄做条件锁的抉择 | **0 个** |

**两个致命结论：**

1. **体魄是纯消耗品**：只有 5 个抉择能加（每线 1 个、全在第 3 章、只 +1），却有 20 个减。
   → **不能拿体魄当生死闸**（探针实测：乱点 15.14% 暴毙，等于随机杀人）。它的真实作用是"几道选项锁"和叙事噪声。
2. **`S.age = chapters[idx].age` 是赋值**，会覆盖任何累加。
   → 任何"改寿命"必须先把这个赋值改成加法基底，否则 `years` 写了也会被下一章冲掉。**这是本设计的第一个工程点。**

---

## 1. 最终方案（探针校准后）

### 第一层 · 寿数（让年龄可被选择改变）

保留每章名义年龄为基准，新增 `S.lifeShift`，每章进入时：

```
S.age = chapters[idx].age + S.lifeShift
```

| 来源 | 偏移 |
|---|---|
| 抉择加体魄（`attrs.vit > 0`） | **+2** |
| 抉择减体魄（`attrs.vit < 0`） | **-1** |
| 拿命换钱（`attrs.coin >= 3 且 vit < 0`） | 额外 **-1** |
| 稳定类 flag（`stay/keep/home/settle`） | **+1** |
| 灯灭（`tough++` 时） | **-1**（「你熬过了一次，也少活了一点」） |
| 上限 | `lifeShift` 封顶 **+6**，不与下限对称 |

> 分配要点：**大多数抉择偏移为 0**。寿命必须是"少数选择累积出来的结果"。

### 第二层 · 年龄三带（用年龄分出三种"死法"）

判定顺序：`早夭 → 现有覆盖层 → 年龄三带 → 七桶`
（**七桶一个都不动**，年龄层只在两端各切一刀）

| 结局 | 条件 | 实测命中（random / health / selfdestruct） |
|---|---|---|
| **灯没熬过那个冬天**（早夭） | 第 8 章起 且 `lifeShift <= -6` | 0% / 0% / **0%** |
| **未及白首** | `age <= 74` | **0.61%** / 0% / **13.97%** |
| （中段，沿用现有 15 结局） | `75 ~ 80` | **96.53%** / 100% / 86.03% |
| **灯尽油枯** | `age >= 81` | **2.85%** / 0% / 0% |

终局年龄分布（各 20000 局）：

```
random       p10=76  中位77  p90=79   范围 74~81
health       p10=79  中位80  p90=80   范围 79~80
selfdestruct p10=74  中位75  p90=75   范围 74~75
```

**中段七桶结构未被扰动（硬红线已验证）**：

| 策略 | 中段七桶分布 | 与本设计前对比 |
|---|---|---|
| random | 远行者 26.6 / 执灯人 18.1 / 传灯者 13.4 / 灯与雪 13.0 / 缺一角 9.6 | 26.6 / 18.1 / 13.4 / 13.0 / 9.6 —— **逐项一致** |
| selfdestruct | 金灯无芯 46.9 | 46.7（本设计前） |

## 2. 探针暴露的两个真问题（必须先看清再决定）

### 问题一：早夭目前**不可达**（0%）

`lifeShift` 的负面来源总共只有：20 个减体魄抉择 + 灯灭。极端自毁策略实测中位偏移仅 **-3**，
够不到 `-6`。要么把阈值放宽到 `-4`（自毁约 40%，偏惩罚），要么接受"早夭在现有内容下打不出来"。

**建议**：先**不放早夭**，只上「未及白首 / 灯尽油枯」。等 §3 的内容补完再开。

### 问题二：养生流**没有奖励**

health 策略年龄中位 80、范围 79~80，**永远进不了 `age>=81`**，也就是说：
"爱惜身体"这条路在年龄维度上**什么都不给**。根因还是「只有 5 个加体魄的抉择、全在第 3 章」。
而且 health 策略的结局是 **100% 点灯的远行者**——它本来就没有出口。

**结论：年龄机制的"体感"受现有内容总量限制。**
引擎层能做到"年龄会变、结局会随之分带"，但做不到"寿命是一笔值得经营的账"。

## 3. 内容缺口（若要年龄真正成为维度）

| 缺口 | 现状 | 建议 |
|---|---|---|
| 加体魄的抉择 | 5 个（每线 1，全在第 3 章） | 第 6/8/11 章各补 1 个"爱惜身体"向抉择（`vit +1`，代价是别的属性） |
| 稳定类 flag | 极少 | 第 5/7 章各补 1 个"留下来"向抉择 |
| 长寿命抉择的分布 | 全挤在第 3 章 | 12 章摊开，让"活多久"是全程累积的结果 |

补完后 `lifeShift` 的可达区间会从现在的 `[-4, +2]` 扩到 `[-6, +6]`，
早夭与灯尽油枯才都成为"刻意为之才拿得到"的结局。
