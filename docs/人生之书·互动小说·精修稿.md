## 灯谱（全篇状态结算的唯一依据）

一生收集/点亮/熄灭的灯，共 18 种，分三组：

| 组 | 灯 | 意象 |
|---|---|---|
| **亲缘·根** | 念 · 担 · 守 · 孝 · 欠 · 融 | 与家人、故乡的联结 |
| **奔途·光** | 路 · 踮 · 远 · 滚 · 追 · 桥 | 出走、奋斗、重逢 |
| **心性·灯芯** | 藏 · 痴 · 诚 · 暖 · 归 · 传 | 内在质地与回响 |

- 每个抉择点亮/点亮+1（＋灯）或让某灯更暗（－灯）。
- 允许「灯·转化」：如 欠 → 孝（第10章 B），守 渐暗不灭（第9章 C）。
- 结算时看三样：**主灯**（累计最亮的一盏）、**韧度**（熄灭过却未放弃的总数）、**回响**（传 与 桥 是否点亮）。

# 序章 · 二〇〇一年的雪

二〇〇一年冬，小城的雪下得很大。

产房外，你父亲靠着墙，一支烟夹在指间，没舍得点——腊月里，医院的走廊比外头还冷。他反复把那张皱巴巴的票子从口袋摸出来又塞回去，那是他跟工友借的，打算给护士道声辛苦。

后来护士抱着你出来，说："是个小子，哭声真亮。"

> （若生为女儿，护士说的是："是个闺女，哭声真亮。"——这句在引擎里按随机性别取用。）

你父亲那支烟，那一刻在手里断了。他没去看你，先抬头看了看窗外。

雪还在下。

多年以后，你听母亲讲起那个夜晚，说她当时心里想的是：这孩子，赶着大雪天来，怕是个有故事的人。

你的人生，从那个雪夜开始。

**而第一个抉择，其实早就替你做好了——你出生了，你没办法不活。**

# 第一章 · 巷子与水井

你的童年，是一整条巷子。

巷口有一口老井，井沿被磨得锃亮。你祖母喜欢在井边洗衣裳，你在她脚边玩水，水花溅起来，落在青石板上，像一群散开的星。祖母说："井里的水是照人一生的，你看，日头一照，什么都在里面。"

你那时不懂。你只知道，巷子里的人家，晚饭都是搬出来蹲在门口吃的。大人端一碗，小孩端半碗，谁家的菜香了几条巷子都闻得见。

你父亲在厂里上夜班，你常一个月见不到他几次。有一回他难得早归，给你带回一只纸折的青蛙。你不会折，他也不会教，父子俩对着那只青蛙沉默了一下午。后来那只青蛙被水浸坏了，你没舍得扔。

然后，某一天，你母亲说要去南边打工。

那是你人生里，第一场真正的雪。

祖母在井边替你擦脸，说："别哭，大人是去挣钱的。井里的水不会枯，你妈会回来。"

你信了。

**抉择一：那个早晨，她背着包跨出院门时——**

- **A. 你追出去，拉住她的衣角。**——你母亲蹲下来，眼睛红了，说"乖，妈很快回来"。你在巷口站着，看她走上桥，看她的背影越来越小，直到融进雪里。
  → **＋【念】**。往后的年月里，"等"这个字，学会了咬人。
- **B. 你懂事地挥手，说"妈，你放心，我照顾奶奶"。**——你母亲没敢回头。她怕一回头就走不成。你那天中午，独自把井边的一盆衣裳洗了。祖母看见了，没说话，背过身去抹眼睛。
  → **＋【担】**。从此你习惯把话咽下去，把事扛起来。
- **C. 你低着头，没哭，也没送。**——你躲进屋里，假装在写作业，其实一个字都没写。那个下午，比一整年都长。
  → **＋【藏】**。你把心事收进身体里最底的一格，后来许多年，没人打得开。

# 第二章 · 桥下的灯

你母亲每年回来一次。回来时，你的尺寸就大了半号；她走时，你又瘦回去一些。

祖母的背越来越弯。她教你认字，用井水在青石板上写"人"字，说："人字两笔，一笔靠你自己，一笔靠别人帮扶。你看，写好了，才立得住。"

厂子改制那几年，你父亲买断工龄回了家。他不再上夜班，天天坐在门口发呆。有一回你放学回来，看见他在井边，把一支烟点燃、掐灭、再点燃，反反复复。你没敢过去。他抬头看见你，笑了笑，说："回来啦。"那天晚上，他把你的作业本拿去，翻得哗哗响，说："好好念，别跟爹一样。"

小城里通往中学的路，要过一座石桥。桥下常年停着一只旧船，拴船的铁环锈迹斑斑。你每天天不亮走过桥，桥头路灯坏了大半年，没人修。

那年冬天，你把奖学金单子拿回家。你父亲看了很久，最后只说了一句："要好好念啊。"他把单子折好，塞进贴身的口袋。

后来你才知道，那天他其实想说的是：爹这辈子是不行了，你好好的。

**抉择二：中考出分那晚，家里为学费犯了难——**

- **A. 你说"爸，我不念了，我去挣钱"。**——你父亲摔了手里的碗。碗碎了一地，他红着眼睛吼："谁让你不念的？"可吼完，他又坐下来，像一只泄了气的旧轮胎，说，"是爹没本事。"
  → **＋【担】**。你第一次学到：穷，不是原罪，无能为力才是。而"不念了"这三个字，你在心里念了很多年。
- **B. 你报考了免费的师范/技校。**——你父亲那天沉默了很久，最后说"好，咱家能出人就好"。你后来在技校里，每天把手上的茧磨厚一层，见了所有能见的光。
  → **＋【路】**。你学会不为梦想委屈任何人，只委屈自己。
- **C. 你赌气说"我要考最好的高中，考不上就不回来了"。**——你父亲没说话。半夜你醒来，听见他压着嗓子跟你母亲说："把咱家那条老宅抵了吧，孩子有出息是大事。"
  → **＋【踮】**。你站在全家人的肩膀上够高处，那滋味，既是甜，也是沉。

# 第三章 · 十七岁的信

十七岁那年，你的课桌腿下，多了一封信。

那个总在课间回头看你的人转学了，走前把它压在课桌下面。你发现它时，人已经走了三天。信很短，字很好看，写着："你总发呆看窗外，到底在看什么？"

你没有回信的地方。那封信，你夹进了一本叫《边城》的书里。

> （写信人与主角同年同班，性别随主角而定：生为男儿时是那位**女同学**；生为女儿时是那位**男同学**。下文 B 选项里的"她/他"随此切换，引擎按性别取用。）

**抉择三：那封信，你最终——**

- **A. 没回，把它长久地夹在书页里。**——后来你搬家，书卖给了收废品的。你站在巷口，看着载着书的三轮车走远，忽然觉得青春那页，翻过去了。
  → **＋【念】**。有些话，没有寄出的地址，就只好说给岁月听。
- **B. 你追去了她的新学校。**——你跑了一下午，找到那所学校，站在门口，人山人海里没有她。你在路灯下站到天黑。后来你们再没见面，但那份"跑过去过"的勇气，陪了你很多年。
  → **＋【滚】**。你从此知道：有些事情，做过，就不算遗憾。
  > （生为女儿时，B 选项为：你追去了**他的**新学校——人山人海里没有**他**。）
- **C. 你回了一封，用井水般的字迹，寄到学校，被退了回来。**——信退回那天，你把它压在枕头下，让那股墨香陪你睡了很多年。
  → **＋【痴】**。你会用很长的时间记得一个人。这是福，也是劫。

# 第四章 · 绿皮火车

高考那年夏天，天极热。

你坐在闷热的考场里，笔尖在答题纸上沙沙地响，像那年井边祖母搓洗衣裳的声音。考完最后一科，你走出校门，看见你父亲站在树荫下，手里攥着一瓶汽水，看见你出来，赶紧递过来："解解暑。"

他没有问考得怎么样。他只是说："走，回家吃饭。"

后来，成绩出来了。分数线差了两分。

那一晚，你父亲抽了很多烟。他后来走进你房间，说："复读，爹供你。咱家砸锅卖铁也要供你。"

**抉择四：录取通知差两分，复读还是南下？**

- **A. 复读一年。**——你把自己关进没日没夜的题海里。第二年，你考上了。放榜那天，你父亲把录取通知书翻来覆去看，看得眼泪都快出来了，嘴上却说"这有啥好看的"。
  → **＋【踮】**（封格）。你开始确信：一步之差，可以靠两百个夜晚追回来。
- **B. 你说"爸，我走技术路线，早点挣钱"。**——你背起那个蛇皮袋，坐上了南下的绿皮火车。靠窗的位置，对座大叔吃泡面的味道，你记了很多年。窗外是倒退的麦田、丘陵、陌生的城市。你忽然觉得，人生是一条铁轨，你第一次踩了上去。
  → **＋【路】**。它从你的血脉里亮起来。
- **C. 你两条都想，于是去了一所学费便宜的外省学校。**——你挑挑拣拣，最后上了车。车开动那刻，你回头，看见你父亲站在月台上，越来越小，像井边一枚晒干了的核桃。你攥紧车票，告诉自己：一定要活出个人样。
  → **＋【远】**。你开始长出自己的方向，却也长出了"离家"的疼。

# 第五章 · 出租屋与第一份工钱

大城市不相信眼泪，也不相信毕业证。

你租了一个城中村的小单间，墙皮斑驳，一张床、一张桌、一扇朝北的窗。窗外那盏路灯，每晚准时亮，像是城里唯一愿意陪你的东西。

第一份工作，你站流水线/跑业务/敲代码，一天十二个小时。第一个月工资到账那天，你站在 ATM 前，看着那一串数字，第一次觉得，自己是个大人了。

你给家里打视频，祖母在画面那头笑："我娃瘦了。"你说："没有，胖了。"

你父亲在旁插了一句："钱自己留着花，别饿着。"

**抉择五：第一个月工资，你怎么安排？**

- **A. 分一半寄回家。**——你妈在电话里"怪"你乱花钱，声音却有点抖。你爸难得说了一句："好孩子。"就是这两个字，让你在地铁上，眼眶热了很久。
  → **＋【担】**。你的根，扎得很深。
- **B. 全留给自己，报了个夜校/买了台二手电脑。**——你赌在自己身上。后来这技能，成了你糊口又立住的本事。你偶尔想起那封信、那座桥，想起祖母说的"人字两笔，相互扶着才立得住"——你觉得自己正在给自己补上第二笔。
  → **＋【路】**（封格）。
- **C. 请舍友/同事吃了顿饭。**——你第一次尝到"人情往来"的甜和重。那顿饭大家都很高兴，笑声响彻出租屋。你忽然明白，在大城市扎根，光靠力气不够，要靠一张笑脸搭起来的桥梁。
  → **＋【桥】**。你和这世界，开始互相握手。

# 第六章 · 那支没点着的烟

你恋爱了。

> 生为男儿：她是在同城一家公司上班，笑起来眼睛弯弯的。你们走过这座城市的大街小巷，你把工资的一小半，都花在了"带她吃好吃的"上。你觉得人生开始有了光的形状。
>
> 生为女儿：他是在同城一家公司上班，笑起来眉眼温和。你们走过这座城市的大街小巷，你把工资的一小半，都花在了"带他吃好吃的"上。你觉得人生开始有了光的形状。

后来，你父亲病了。你回去，看见病床上的他，瘦了一大圈，还笑着跟你说"小毛病，别担心"。

你请假照顾了几天。临走那晚，你父亲支开你母亲，从枕头下摸出一样东西——你小时候那只纸青蛙旁边，另一样他珍藏的东西：一张泛黄的照片。年轻的他在厂门口，意气风发，身后是雪。

他说："你爹我这辈子，没给你挣下什么，就这一身硬骨头和这颗要强的性子，你拿去吧。"

你回城那天，火车站，你父亲没来送。你后来才知道，他偷偷站在二楼的窗后，看了你很久。

**抉择六：父亲病中，你还走吗？**

- **A. 你先留下来，把工作安顿好再回。**——你在老家多待了两周。那两周，你陪他下棋、给他读报、看他在院子里晒太阳。你后来总说，那是你人生里，最好的两周。
  → **＋【守】**。你开始明白：有些好东西，是留不住的，所以要在手边的时候，看够它。
- **B. 你赶回去上班，承诺"忙完这阵就回"。**——"这阵"忙了很久。后来你接到电话，说你父亲进了抢救室。你赶回去时，他已经不认识了。你跪在病床前喊"爸"，他浑浊的眼睛动了动，却没有应你。
  → **＋【欠】**。你没有错过他的生日，却错过了他的告别。这盏灯，后来任你点多少遍，都没能亮成光。
- **C. 你把工作辞了，回去陪他。**——你妈说"你傻呀"。你说："妈，工作没了可以再找，爸就这一个。"那段时间你陪他走完最后一程，他走得很安详。后来你慢慢还清了债，重新出发。
  → **＋【孝】**（最沉的一盏）。你欠世界一点前程，但你不欠父亲一个告别。

# 第七章 · 灵前的灯

你父亲走的那年冬天，小城又下了一场大雪，像极了你出生的那年。

你跪在灵前，一晚上没合眼。你想起他在井边反反复复掐灭的那支烟，想起他把你奖学金单子塞进贴身口袋，想起他说"人字两笔，要立得住"。

你忽然明白：他这辈子，只教会了你两件事。一是"别怕"，二是"好好的"。

灵堂里的灯，一夜都没灭。

**抉择七：父亲走后，你的"念想"该怎么办？**

- **A. 你把他那支没点过的烟，收进了盒子里，留作念想。**——很多年后，你打开那个盒子，烟已经潮了。你对着它说："爸，我挺好的。"
  → 你把他"好好的"三个字，记了一辈子，活成了一辈子。（【念】+1）
- **B. 你把他的照片，摆在了新家最高的柜子上。**——每天出门前看一眼。你笑着说"爸，我出门上班了"，像他还在的时候。
  → **＋【传】**。你开始替他，看这世界看下去。
- **C. 你既没有留烟，也没有摆照片。**——你把他记在心里，连同那晚的雪、井边的水、巷口的灯。有些人生不需要遗物，因为他已经长成了你。
  → **＋【融】**。他的一部分，从此在你身体里，继续活着。

# 第八章 · 四十岁的风暴

四十岁那年，你被裁员了。

你没哭，也没闹。你在写字楼楼下站了一会儿，看着那栋你待了十年的玻璃楼，然后转身，走进地铁站。手机上，房贷的短信安静地躺着。

你开始重新投简历。三十五岁是一堵墙，四十岁是另一堵更高的墙。你学会了一个新技能：在 HR 面前，把"我快四十了"这句话，翻译成"我有二十年的经验"。

> 生为男儿：你妻子说："要不，我们回老家吧。"
>
> 生为女儿：你丈夫说："要不，我们回老家吧。"

你站在窗边，看着城中村那盏陪了你很多年的路灯，它还在亮。

**抉择八：风暴中央，你的路——**

- **A. 你决定留下，转型重来。**——你报了班，从头学新东西，像二十岁那样重新当学生。无数次想放弃，无数次在深夜擦干眼泪继续。后来你在新赛道站稳了。孩子问你"你后悔吗"，你说："不后悔，人输了牌，可以重新洗。"
  → **＋【路】＋【踮】**。你成了那个"翻了两次盘的人"。
- **B. 你带着全家回了老家。**——那座小城，井还在，桥还在，巷子里的青石板还在。你接手了父亲留给你的老屋，修了修，住了下来，每天沿桥散步，跟老邻居打招呼。你发现：人一辈子，走遍千山万水，最后想回的，还是那口井边。
  → **＋【归】**。你从浪头上走下来，落在岸上，踏实了。
- **C. 你既不甘心留下，也不舍得回去，两头飘着。**——你开始接零散的活，今年这里明年那里。你常年在路上，看过很多个城市的深夜。你偶尔想起那句"好好念，别跟爹一样"，忽然发现——你其实一直在追一个"好好的"的定义。
  → **＋【追】**。你还不确定答案，但你在路上。这就是你的人生。

# 第九章 · 凌晨三点的厨房

你婚姻里的裂缝，是慢慢裂开的，像青石板上的细纹。

你们很多年没有好好说话了。晚上，各自抱着手机，隔着半米，却像隔着一条河。

某一个凌晨三点，你睡不着，起来下厨房煮面。

> 生为男儿：你听见她也没睡着，翻身的声音。你端着两碗面，走到她床边，说："要不要吃点？"她愣了很久，接过面，低着头，眼泪"啪嗒"掉进碗里。
>
> 生为女儿：你听见他也没睡着，翻身的声音。你端着两碗面，走到他床边，说："要不要吃点？"他愣了很久，接过面，低着头，眼泪"啪嗒"掉进碗里。

那一晚，你们聊了很久很久。聊年轻时，聊孩子，聊这些年各自的委屈。

**抉择九：裂缝面前，你的双手——**

- **A. 你主动修。**——你记住对方爱吃的、对方怕的、对方没说的。你们开始在每个周末，留出半天，谁都不碰手机，就像两个刚认识的人那样重新约会。
  → **＋【暖】**。婚姻这东西，原来不是熬，是修。
- **B. 你还是开了口，坦诚这些年藏着的委屈。**——你告诉对方：父亲走时、你失业时、你深夜一个人站在窗边时，心里都在想什么。对方听完说："你怎么不早说。"你们抱头痛哭，哭完，忽然都轻了。
  → **＋【诚】**。原来扛着不说的，不只是你一个人。
- **C. 你把那碗面端到对方面前，然后还是没说出口。**——你们相敬如宾又过了几年，像井边的两只旧桶，各自晃荡，谁也不碰谁。
  → **－【守】**（暗了些，但没灭）。有些河，你选择不趟过去，也是一种选择。

> （第九章正文里的"她/他"为同一人——你的爱人。引擎中整章按所生性别取用男版/女版，以上选项已中性化为"对方"。）

# 第十章 · 母亲的背影

母亲老了。她开始常常坐在井边（如今井早枯了，被盖上了石板），一坐就是一下午。

她记性越来越差。她有时会突然问你："你是谁呀？"你笑着答："我是你儿子啊——你连{名}都不认得了？"她"哦"一声，过一会儿又问。

> （生为女儿时，你答的是："我是你闺女啊——你连{名}都不认得了？" {名} 为引擎随机抽到的名字。）

她忘了很多人，却总记得出去给你买爱吃的菜，记得给"她的娃"留一盏灯。

你发现，那个在雪夜里抱着你的人，现在需要你抱了。

**抉择十：母亲最后的时光，你——**

- **A. 你把她接来同住。**——家里多了一个"老小孩"。你学着给她做饭、理发、换药。她夜里会突然醒来说"我怕黑"，你就把走廊的灯留着，整夜整夜地亮。
  → **＋【守】＋【孝】**。你成了她的井，她的桥，她的灯。人一辈子，就是一场"被照亮"与"去照亮"的接力。
- **B. 你每周都回去，风雨无阻。**——你是医生常客，是小城的常客，是那间老屋的常客。亲戚们都说"真孝顺"。只有你知道，你是在补一种遗憾——父亲那盏没点上的烟，你想在母亲身上，把它点上。
  → **【欠】转化为【孝】**。有些意难平，是可以用余生去抚平的。
- **C. 你也在忙，总说"忙完这阵就回去"。**——你打视频，她在画面那头笑："你忙你的，妈好着呢。"你挂了电话，心里一阵空。后来你终于回去了，她拉着你的手，说："等你好久了。"那天晚上你睡在老屋，半夜，她轻轻起来，给你掖了掖被角。
  → **＋【欠】**。你忽然明白：世界上所有的"来日方长"，都敌不过一句"等我回来"。

# 第十一章 · 一个人的房间

退休那天，你走出办公楼，太阳刺眼。

你站了一会儿。没人来接你。你自己回了家，打开门，屋里很安静。

你把屋子收了一遍，给自己下了碗面。面有点咸，你想起你妈总说你"毛手毛脚"。

你坐到窗边，看楼下的孩子放学、奔跑、吵闹。你想起你也曾是这样的小孩，在井边玩水，把青石板溅得星星点点。

你打开那个旧盒子。

里面有：一只发潮的纸青蛙、一封信（那一封没有寄出的）、一张你们家的老照片，还有十几张车票、几片干枯的叶子。

这是你的一辈子。

**抉择十一：面对这一盒子，你——**

- **A. 你把它们一件件摆好，像文物一样珍惜。**——你决定写一本书。把井、巷子、桥、大雪、绿皮火车、凌晨三点的面，全写进去。写到最后一页，你写："这一生，我点过很多灯，也熄过几盏。愿读到这里的人，都有人给留灯。"
  → **＋【传】**（大亮）。你的一生，化成了别人床头的灯。
- **B. 你约上了仅剩的老友，每周末聚一次。**——你们坐在桥头，看河水，讲旧事。有人已经听不清了，就笑着看别人笑。你们都说"下辈子还当朋友"。
  → **＋【桥】**。原来晚年最贵的，不是钱，是还有几个人，记得你的名字。
- **C. 你把盒子合上，放在枕边，什么也没做。**——你只是每天睡前，打开看一会儿，再合上。像在给这一辈子，轻轻翻页。
  → **＋【念】**。有些人生不必写成书，它的读者，只有你自己。

# 第十二章 · 最后一场雪

你走的那天，下着小雪，像极了序章那一年。

你躺在床上，透过窗，看见雪落在老屋的屋檐、落在青石板、落在远处那座桥。你恍惚看见许多个自己——雪夜的婴儿、井边的孩子、绿皮火车上靠窗的年轻人、写字楼下转身的中年人、窗边喝茶的老人。

他们都在看你。

你笑了笑。

窗外，好像有人给一盏灯，轻轻罩上了一个罩子，免得雪把它打灭。

**抉择十二：最后的你，留给世界什么？**

- **A. 一通电话。**——你用最后一点力气，给每个人打了电话，说"我挺好的，你们好好的"。电话那头的人不知道，这一句"挺好的"，是告别。
  → 你留给世界一份"好好的"。你这一生点过的灯，全化成了这一句。（【传】+1）
- **B. 一封信/一本书。**——你留下了那本写满一生的书。后来有人读到那句"这一生，我点过很多灯，也熄过几盏"，在深夜的灯下，哭了很久。
  → **＋【传】**（封顶）。你的声音，越过生命的终点，还在说话。
- **C. 什么都没有，只拉了一下窗闩。**——你抬手，把窗帘轻轻拉开一角，让雪光透进来。然后你闭上眼，睡了，像走完一场很长的夜路，终于到家熄灯。
  → **＋【归】**（封顶）。你与世界，两清了。你不是输了，你是完成了。

雪落无声。

你这一生，最后落下的，是青石板上，一声极轻极轻的"嗒"。

像一串星，落回井里。

# 终章 · 结局结算规则（可引擎化）

结算按三步匹配，命中即停：

1. **隐藏结局（极稀有）**：同时点亮 念、担、路、孝、传、归、暖（≥6 盏主灯）→ 《点亮万盏灯》。
2. **主线结局**：取累计最亮（点亮次数最多）的那一盏，映射到六套结局骨架；再叠加第二关键灯微调叙事语气。
3. **韧度/回响**：若【欠】曾经点亮但最终熄灭/转化（如转【孝】），结局语气从"至虐"转"和解"；若【传】或【桥】点亮，结局补充一句"灯传到别人手里"的收尾。

## 六套结局（骨架不变，语气随灯微调）

- **执灯人**（孝/守/传 为主灯）——人间烟火中，灯最亮。
- **点灯的远行者**（路/踮/追/远 为主灯）——曾被看轻的孩子，逆风翻盘，走了很远。
- **守灯的人**（守/暖/诚/桥）——把寻常日子过成诗。
- **缺一角的灯**（欠/藏 为主灯，至虐向）——一生与遗憾和解。
- **灯与雪**（念/痴/归/滚）——一生在找"归宿"，最终回到出发的地方。

# 后记 · 作者的留言

亲爱的读者，你已经走完了一段完整的人生。

这部"小说"，没有标准答案。无论你最终点亮了几盏灯、熄灭了几盏灯——**你写的这个自己，都是唯一且值得的。**

我只想在这个后记里，留给你三句话，当作这场验证人生之后的歇脚：

1. **"人字两笔，一笔靠自己，一笔靠别人帮扶，写好了，才立得住。"**——如果这一生有什么真理，大概就是"识得相依"。
2. **"有些好东西是留不住的，所以要趁在手边时，认真看够它。"**——去抱抱你爱的人吧，趁灯还亮着。
3. **"不管拿到了什么开局、遇到了什么样的人生，都别轻易选择重来。"**——这一局，你已经尽力点亮了足够多的灯。现实里没有按钮，愿你珍惜眼前这一盏独一无二的、活生生的人生。

愿你在现实里，也一直有人，为你留着一盏灯。
