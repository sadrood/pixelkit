# AI 聊天界面重设计（2026-09-30）

> 涉及文件：`index.html`（页面结构）、`src/styles/agent.css`（新增，全部规则以 `#page-agent` 作用域）、
> `src/pages/AgentPage.js`（交互逻辑）、`scripts/ui-contrast-check.mjs`（对比度巡检）。

## 1. 改之前的问题（都是实测出来的，不是感觉）

| 问题 | 实测证据 |
| --- | --- |
| **发送按钮白底白字**（字看不见） | `getComputedStyle` → `color: rgb(255,255,255)` + `background: rgb(255,255,255)`，对比度 **1.0**；根因是外壳 `#app .btn-primary` 用 id 选择器压过了组件样式 |
| **桌面端只用了中间 820px** | 视口 1256px，容器 `max-width:820px` 居中 → 左右各浪费约 218px |
| **气泡收缩成窄条** | `.agent-msg` 是 `max-width:85%`，但气泡自身 `max-width:none` → 实际只有 **356px** |
| 缺功能 | 没有头像、时间、消息操作（复制/重新生成）、空状态引导、模型选择、停止生成、会话历史 |
| 底部拥挤 | 一行塞了 2 个勾选开关 + 提示文字 + 动态插入的「新对话」按钮 |
| 流式无中断手段 | 代码里有 `AbortController`，但界面没有暴露停止入口 |

## 2. 改之后的取向：现代对话式

- **全宽工作区**：左侧会话侧栏（248px，可收起；窄屏变抽屉）+ 右侧对话主区，不再限宽 820px。
- **消息行**：头像（助手用站点颜文字表情，用户用 🧑）+ `.pk-body`（标签 / 气泡 / 操作条）。
  助手气泡最大 72ch、圆角 14px，用户气泡右对齐、品牌深橙底白字。
- **操作条**：hover / focus 才出现（触屏常显）—— 复制（所有消息）、重新生成（助手消息）。
- **空状态**：机器人图标 + 一句话介绍 + 4 个可点击的建议词（画信息图 / 查最新资讯 / 改文案 /
  解释概念），点一下即填入并发送。
- **输入卡片**：圆角卡片 + focus 高亮环；附件/语音按钮在卡内；textarea 自动增高（1~6 行）；
  流式期间把「发送」换成「■ 停止」。
- **顶部信息条**：模型下拉（未开通项置灰标注）+ 深浅主题切换 + 清空当前对话。
- **流式光标**：气泡尾部 `▍` 闪烁，生成结束自动移除。
- **深浅两套主题**：复用站点 `--bg/--surface/--border/--text/...` 变量与 `data-theme="light"` 规则，
  聊天页内可直接切换（写同一个 `pk_theme`）。

## 3. 对比度：按钮底为什么不是品牌橙

品牌橙 `#ff6b4a` 配白字只有 **2.7:1**（AA 要求 4.5:1），这是"字看不见"的同一类坑。
所以按钮底色改用加深的 `--pk-brand-strong: #c2401d`：

- 白字在其上 **5.19:1**（实测，`scripts/ui-contrast-check.mjs` 输出）；
- 品牌橙仍用于描边、chip hover、强调色，视觉上仍是同一族。

**复核方式（可回归）**：

```bash
# 本地起站点后
node scripts/ui-contrast-check.mjs --url http://127.0.0.1:3011/ --page agent --themes light,dark
# 线上旧版（用来验证巡检确实抓得住事故）
node scripts/ui-contrast-check.mjs --url http://139.9.176.191:3002/ --basic pixelkit:test123 --page agent --themes light
```

实测对照：

| 版本 | `#agent-send-btn` | 结论 |
| --- | --- | --- |
| 线上旧版（e480877） | 白字 / 白底 → **1.0** | ✗ CRITICAL，退出码 1 |
| 重设计后 | 白字 / `rgb(194,64,29)` → **5.19** | ✓ 浅深两主题 0 FAIL / 0 CRITICAL |

巡检脚本的边界（已知不能验的）：纯渐变/背景图底色会上报 `UNVERIFIABLE`（不计失败）；
不模拟祖先 `opacity`；只扫描当前显示的 SPA 页面（其他页要 `--page <名字>` 单独跑）；
伪元素文字、图片上的文字不在范围内。

## 4. 行为清单（浏览器实测通过）

- 点建议词 → 立即出现用户气泡 + 助手占位 + 头像 + 流式光标，空状态自动隐藏；
- 流式中「发送」隐藏、「■ 停止」出现；点停止 → 中断请求、恢复按钮、移除光标；
- 消息操作条：助手消息 2 个按钮（复制 / 重新生成）、用户消息 1 个（复制）；
- 模型下拉：6 个候选，`deepseek-v4.1-flash` 置灰标注「未开通」，选择写入 `localStorage`；
- 会话侧栏：列出本机最近会话（预览 + 相对时间 + 条数），点击加载、悬停可删；
- 窄屏（390×844）：侧栏自动收起为抽屉，顶栏压缩，消息与输入区单列排布；
  视口变化（旋转/拖窗口）会自动跟随，不会卡在半开状态。
